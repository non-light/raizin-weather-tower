# RAIZIN WEATHER TOWER

<p align="center">
  <img src="assets/raizin.png" alt="雷神 (RZ)" width="300">
</p>

雷神マスコットがナビゲートする、**ジェンガ風の3Dタワーゲーム**（試作版）。
ブロックを1本ずつ引き抜いて一番上に積み、崩さずにどこまで伸ばせるかを競います。

普通のジェンガと違うところ。

- **天候**：ターンごとに変わる（☀️晴れ / 🌫️霧 / 💨風 / ⛈️嵐）
- **カラールーレット**：ターンごとに条件を抽選し、**その条件のブロックしか抜けない**
- **称号**：プレイ内容から50種類の称号を判定。**称号図鑑**に記録が残る

ブラウザだけで動きます。Three.js + cannon-es + Vite。

## 遊びかた

```bash
npm install
npm run dev
```

表示された `http://localhost:5173` を開きます。

| 操作 | 内容 |
| --- | --- |
| SPIN ボタン | カラールーレットを回して、今回抜ける色を決める |
| 指定色のブロックをクリック | 選択（黄色い輪郭が出ます）。他の色は動きません |
| そのままドラッグ | ブロックの長手方向へ引き抜く。**左右どちらへも抜ける** |
| （完全に抜けると自動で配置モードへ） | 最上段に置き場所の候補が3か所光ります |
| マウス移動 | 置き場所をプレビュー（ブロックが半透明でその上に浮きます） |
| 候補をクリック | そこへ配置。+100点 |
| 右クリック | **ぐっと少しだけ押し戻す**（完全リセットではない。何度か押せば元の位置まで戻せる） |
| `Esc` | やめて元の穴まで戻し、手を離す |
| 何もない所をドラッグ | カメラを回す |
| ホイール | ズーム |

タワーのブロックが3本以上落ちると **GAME OVER** です。
崩れてもすぐには結果画面になりません。**4秒ほど崩れていく様子を眺めてから**、
ゆっくり結果と今回の称号が発表されます。

ジェンガと同じく、**最上段** と（最上段が3本揃っていないときは）**その1つ下の段** からは抜けません。

### 画面とターンの流れ

```
TITLE ──▶ BOOK（称号図鑑）
  │
  └▶ INTRO ─▶ WEATHER_CHANGE ─▶ ROULETTE ─┬─▶ SELECT         （通常色）
                    ▲                     ├─▶ COLOR_CHOICE ─▶ SELECT （⚡）
                    │                     ├─▶ SELECT_FREE    （🌈）
                    │                     └─▶ SELECT_DANGER  （⬛）
                    │                              │
                    └── SETTLING ◀─ PLACING ◀─ PLACEMENT ◀─ PULLING
```

ページを開くとタイトル画面から始まります。**「ゲームスタート！」を押すまで、
天候もルーレットもスコアもターンも一切進みません。**

途中の工程は飛ばせません。とくに **完全に引き抜くまで配置モードには進めません**。
判定は「元の位置から十分離れている」かつ「どのブロックとも重なっていない（AABB判定）」の
両方を満たしたときだけです。中途半端なところで手を離すと雷神が
「もう少し引き抜こう！」と教えてくれます。

### 引き抜きの向き

ブロックはそれぞれの**長手方向の1軸**にだけ動きます。段ごとに90度向きが変わるので、
横向きの段なら左右へ、縦向きの段なら奥／手前へ。**どちら側へ抜くかはプレイヤーが決めます。**

**端のブロック（各段の左右）は、長手方向と「タワーの外側への横方向」を
同時に使えます。** 軸は固定されないので、縦に引きながら少し横へ逃がす、
といった斜めの引き抜きができます。

```
縦に少し引く → 重いな… → 横にほんの少しずらす → ずっ… → さらに縦に引く
```

選択すると長手方向に黄色い矢印、横抜きできる側に水色の矢印が出ます
（中央のブロックには水色の矢印は出ません）。横は**外側だけ**で、
タワーの中央へ押し込むことはできません。画面上のドラッグ方向とブロックの見た目の移動方向は、
カメラをどれだけ回しても一致します（カメラ6方向 × 2向き × 2姿勢 = 20通りで確認済み）。

完全に抜けた判定は「真上から見てタワーの外周から出ているか」で見ます。
縦・横・その組み合わせ、どの抜き方でも同じ基準なので、
半分だけ出した状態では配置モードに進めません。

### 右クリックの押し戻し

右クリックは UNDO ではなく「少しだけ押し込んで調整する」操作です。
1回で `PUSH_BACK.DISTANCE`（0.22）ずつ、物理的に押し込みます。実測では
0.965 → 0.749 → 0.534 → 0.318 → 0.102 と一定量ずつ戻り、5回目でぴたりと
元の位置に収まって手が離れます。元の位置より内側へは押し込みません。
押し込んだ勢いは周囲のブロックへも伝わります。

### 横方向は「微調整」

横方向は補助的な微調整として扱っています。感度は縦の 1/4 ほどで、
さらに**速度上限**があるため、どれだけ勢いよくマウスを動かしても
ブロックが一気に飛び出しません。

| 横ドラッグの速さ | ブロックの最大横速度 | 抜けた横距離 | タワーの振れ |
| --- | --- | --- | --- |
| ゆっくり（3px/frame） | 0.25 | 0.13 | 0.032 |
| 激しく（40px/frame） | **0.34（上限）** | 0.32 | 0.066 |

激しく引いてもブロックの速度は上限で頭打ちになり、代わりに**タワーへの揺れが
2倍**になります。「力いっぱい引けば簡単」にはなりません。

### 横抜きの手応え

横抜きは「安全で簡単な抜け道」にならないよう、抵抗を持たせています。
調整値は `src/game.js` の `SIDE_PULL` にまとまっています。

- **すぐには動かない**：静止摩擦を振り切るまで踏ん張る
- **マウスへ直接追従しない**：加速度・減衰・速度上限つきで、じわじわ寄っていく
- **抜き始めが一番重い**：最初の3割はフル抵抗、半分を過ぎると 0.6 倍、
  6割を過ぎると 0.3 倍（接触している長さが減るほど軽くなる）
- **下段ほど重い**：上に載っているブロック数から荷重を出している。
  同じ入力で横が動き出すまでの時間は L1 2.68秒 → L3 2.68 → L5 2.60 →
  L7 2.43 → L9 2.25 秒と、下へ行くほど重くなる
- **タワーが持っていかれる**：接している段から上へ、荷重とテコに応じて力が伝わる
- **少しだけ傾く**：`TILT 0.1 rad` まで回転を許す

調整値は `PULL_TUNING`（`PULL_FORWARD_SCALE` / `SIDE_PULL_SCALE` /
`SIDE_PULL_MAX_SPEED` / `SIDE_PULL_ACCELERATION` / `SIDE_PULL_DAMPING` /
`SIDE_PULL_STATIC_FRICTION` / `SIDE_PULL_DYNAMIC_FRICTION` /
`SIDE_PULL_LOAD_MULTIPLIER` / `PULL_INPUT_SMOOTHING`）にまとまっています。

### 置き場所と重心

置く位置は自分で選びます。端に置けば重心がずれて不安定になり、中央に置けば比較的安定します。
実測では、同じ状態のタワーに置いてから風を当てたとき、最上部の揺れ幅が
**中央 0.157 → 端 0.292**（約1.9倍）になりました。

## カラールーレット

タワーの36本には5色（🔴赤 🔵青 🟡黄 🟢緑 🟣紫）が **偏らないように** 配られます
（8/7/7/7/7）。色は木の地色と混ぜてあるので、木製ブロックの質感は残っています。

各ターンの最初にルーレットが出ます。SPIN を押すと勢いよく回り、減速して1色で停止。
**当たった色のブロックしか抜けません。** 他の色をクリックしても動かず、雷神が
「今回は赤だよ！」と教えてくれます。指定色は画面上部の「指定色：🔴 赤」に
次のターンまで出続けます。

- 指定色のブロックはひかえめに明るくなり、**マウスを重ねたときだけ**輪郭が出ます
  （答えが簡単になりすぎないよう、強い発光はしていません）
- ルーレットが回っている間はブロックの選択・移動・配置がすべてできません
- その色で抜けるブロックが0本のときは「その色はないみたい！ もう一回！」と表示して
  自動的に回し直せる状態になります（ゲームが詰まりません）
- 抜いたブロックは **色そのままで** 最上段に積まれるので、進むほど色の配置が変わります

## 天候

各ターンの終わりに、次の天候が抽選されます（同じ天候は連続しません）。

| | 効果 |
| --- | --- |
| ☀️ 晴れ | 特殊効果なし |
| 🌫️ 霧 | 霧が濃くなり、奥側と下側が見えづらくなる |
| 💨 風 | 数秒おきの突風。弱い→強い→弱い→逆向き、と周期的に変化する |

切り替わった瞬間に画面中央へ大きく `💨 WIND` のように1.8秒表示し、そのあと上部の
小さいバッジへ戻ります。雷神の吹き出しも同時に出ます。

風は見た目と物理の両方で効きます。

- 物理：ブロックへ横方向の力。高い位置のブロックほど強く受けるのでタワーがしなる
- 見た目：画面を横切る風の線、速く流れる雲、雷神が左右に揺れる

強さは「無傷のタワーでも最上部が 0.12 ほど（ブロック幅の約1/4）ゆっくり往復するが、
風だけでは崩れない」ように調整してあります。

## ルーレットの特殊マス

8マス構成（5色 + 特殊3種）。扇の角度は重みに比例するので、見た目と確率が一致します。
確率は `src/colors.js` の `SLOT_WEIGHTS` だけを書き換えれば調整できます。

| | 効果 |
| --- | --- |
| ⚡ 雷神 | 好きな色を自分で選べる（選ぶまでブロックは触れない） |
| 🌈 虹 | 色の制限なし。どのブロックでもOK |
| ⬛ 黒 | 色は自由。ただし **下3段からしか抜けない** |

条件に合うブロックが0本のときは「もう一回、ころころ〜」で回し直せるので、
ゲームが詰まりません。🌫️ 霧 + ⬛ 黒 はかなり難しくなりますが、これは仕様です。

## 称号と称号図鑑

GAME OVER 時に、プレイ統計（`src/stats.js`）から称号を1つ判定します。
称号データは `src/titles.js` に50件まとめてあり、条件・レア度・説明・ヒントを
すべてデータとして持っています。1件追加したいときは配列に足すだけです。

レア度は COMMON / UNCOMMON / RARE / EPIC / LEGENDARY。複数条件に当てはまったときは
レア度 → priority の順に高いものが選ばれ、同点なら複数から1つ選ばれます。

獲得履歴は localStorage に保存され、タイトル画面の「称号図鑑」から見られます。
未獲得の称号は名前が「？？？」になり、ヒントだけ表示されます。
localStorage が使えない環境でも、その旨を表示してゲーム自体は動きます。

## ファイル構成

```
index.html
assets/raizin.png     マスコット画像（差し替えるだけで雷神を変更できます）
src/
  main.js             起動・シーン・ライト・カメラ操作・メインループ
  game.js             ゲーム進行（ルーレット → 選択 → 引き抜き → 積む）と崩壊判定
  tower.js            物理ワールドとタワー（ブロック生成・寸法・物理マテリアル）
  colors.js           5色とルーレットのマス定義、出現確率（SLOT_WEIGHTS）
  roulette.js         カラールーレット（canvas 2D 描画 + 回転アニメーション）
  weather.js          天候（霧・風・嵐）と、その設定値（FOG など）
  stats.js            称号判定に使うプレイ統計
  titles.js           称号50件のマスターデータ（条件・レア度・説明・ヒント）
  collection.js       獲得履歴の保存（localStorage を触るのはここだけ）
  book.js             称号図鑑の画面
  ui.js               HUD、雷神のふきだし、GAME OVER 画面、演出
  style.css
```

マスコットを差し替えるときは `assets/raizin.png` を置き換えてください
（`src/ui.js` がこのファイルを import しています）。画像が読めない場合は
「RAIZIN」と書かれた仮キャラクターにフォールバックします。

## 実装メモ

物理は cannon-es。試作中に踏んだ落とし穴と対処：

- **引き抜き中のブロックをキネマティック（質量無限）にすると、周囲を無限の力で
  押しのけてタワーが暴れる。** 動的ボディのまま速度で動かし、回転だけロックする
  方式にしたところ、引き抜き時の周囲の揺れが 1/20 になった（`setGrabbed`）。
- **積まれたブロック同士の摩擦のままだと、引き抜くときに上の段まで一緒に付いてくる。**
  掴んでいる間だけ摩擦の低いマテリアルへ差し替えている（`slipMaterial`）。
- **接触のバネを固くしすぎると高周波振動がタワー上部で増幅して勝手に崩れる。**
  やわらかめ（`4e6`）＋固定ステップ 1/120 で安定。
- タワーが静止したら **スリープさせる**。眠っている間はまったくズレないので、
  長時間放置しても崩れない。
- **掴んでいるブロックの摩擦は 0 にしている。** 係数 0.08 でも接触点が12個あると
  合計の摩擦力で引き抜けなくなり、「ブロックが動いていないのに引き抜けたことになる」
  原因になっていた。

ルーレットの回転は requestAnimationFrame ではなくゲームループの `update(dt)` から
進めています。こうしておくと `__step(n)` でコマ送り検証ができます。

デバッグ用に `window.__game`（ゲーム状態）と `window.__step(n)`（物理を n フレーム
手動で進める）をコンソールから触れるようにしてあります。

### 霧の調整

霧の濃さは `src/weather.js` の `FOG` オブジェクトにまとまっています
（`DENSITY` / `OPACITY` / `GROUND_OPACITY` / `SPEED` など）。

FogExp2 は距離だけで一様にかかるため、`DENSITY` を上げすぎるとタワー全体が
白飛びします。濃さは「流れる霧」「地面に溜まる霧」のレイヤー側で作っています。

### 難易度について

カラールーレットを入れる前は1ゲーム9〜10ターンほど続きましたが、色が指定されると
安全な中央のブロックを選べないターンが出るため、**1ゲームおよそ2〜7ターン**
（自動プレイ5回の実測）まで短くなりました。難しすぎる場合は、色数を減らすか、
`FALL_COUNT`（崩壊とみなす落下本数）を増やすと調整できます。
